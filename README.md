# 一课时

一款用于管理课程课时的原生微信小程序。用它记录每门课程的类型、总课时与消课进度，并随时查看剩余课时和本月学习情况。

## 当前功能

### 课程管理

- 新建、编辑、删除课程；支持课程名称、分类、总课时、已消课时和颜色标记。
- 按「全部 / 进行中 / 已结课」筛选课程，展示进度、剩余课时与最近消课状态。
- 到期日为可选项，选定后可随时清除；30 天内到期及已逾期课程会在首页和个人页提醒。

### 消课记录

- 消课前可选择具体日期和时间，记录以 `YYYY-MM-DD HH:mm` 格式展示。
- 课程详情可查看历史消课记录；个人页默认展示最近 5 条，并可在“查看全部”中浏览完整记录。
- 自动统计本月已消课时、进行中课程、累计消课时，以及近 6 个月学习趋势。

### 登录与数据

- 首次进入支持微信一键登录，创建个人学习档案；用户资料授权成功时同步头像和昵称。
- 课程和消课记录默认保存在本机；云开发环境可用时可调用云函数同步数据。
- 云端暂不可用时自动降级为本地保存，不会阻塞登录、建课或消课。

## 运行方式

1. 安装并打开[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 选择“导入项目”。
3. 项目目录选择本仓库根目录：`D:\work\one-lesson`。
4. AppID 可选择“测试号”或使用自己的小程序 AppID。
5. 点击“编译”，即可在模拟器中运行。

首次进入小程序需点击“微信登录”。如需启用云端同步，请按 [CLOUDBASE.md](./CLOUDBASE.md) 创建云开发环境并部署云函数。

## 数据说明

新账号从空课程列表开始。课程数据缓存于 `one_lesson_courses`，登录资料缓存于 `one_lesson_cloud_user`。在开发者工具中清除缓存或卸载小程序后，本地数据会被清除。

云开发环境与云函数部署正常时，课程与消课记录可按微信账号同步至云数据库；当前云端不可用时，系统会继续使用本地保存。个人主体小程序不采集手机号。

## 到期提醒与报表

新建或编辑课程时可选填“课程到期日”。未结课且在 30 天内到期的课程，会显示在课程首页和“我的”页面；逾期课程会以红色标记。

“我的”页面中的月度学习报表会汇总最近 6 个月的消课次数。只有使用“消耗 1 课时”功能产生的记录会纳入报表。
